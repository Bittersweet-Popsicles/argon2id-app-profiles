# Python 기반 Argon2id GPU 구현 비교 실험

상용 애플리케이션 세 종에서 관찰한 Argon2id 설정을 바탕으로 두 PC의 공통 batch 32 실험을 분석한다. 이 저장소에는 논문의 수치를 다시 계산할 수 있는 시간 표본, 실험 조건, 집계 코드가 있다.

## 논문 결과 재계산

Python 3.8 이상에서 저장소 최상위 폴더의 다음 명령을 실행한다. GPU, 네트워크, 추가 Python 패키지가 필요하지 않다.

```sh
python reproduce.py
```

입력 파일의 SHA-256과 표본 구성을 확인한 뒤 표 6의 구현 순위와 상대 차이, 표 9의 CPU/GPU 처리량 비율을 출력한다. 주 실험에서는 각 환경과 조건에서 다섯 세션의 측정 시간 25개를 합친 중앙값으로 batch 32를 나눈다. 준비 실행 2회는 중앙값 계산에서 제외한다. 표 6의 분모는 환경 B에서 가장 높은 중앙 처리량이다. 여섯 조건 중 다섯 조건은 두 환경의 최상위가 같다. LunaCam의 후보별 salt 조건은 환경 A의 최상위 구성을 B에서 사용했을 때 -0.36%이다.

표 9는 환경 A에서 같은 앱 설정의 CPU 단일 입력 처리량과 GPU #1의 batch 54 처리량을 비교한다. 비율은 반올림 전 값으로 계산한다. 전력은 측정하지 않았다.

## 자료

| 파일 | 범위 |
|---|---|
| data/protocol.json | 두 PC에 공통인 측정 프로토콜과 앱 설정 |
| data/timings.csv | 환경 A/B 각각 주 실험 150개와 salt 길이 보조 실험 25개의 측정 시간. 세션 번호는 0~4, 측정 호출 번호는 1~5, 시간 단위는 초 |
| data/cpu-a.csv, data/cpu-b.csv | CPU 단일 입력, 준비 2회 후 7회 측정한 기준선 |
| data/additional-a.csv | 환경 A의 보조 실험 집계. phase, batch, units로 측정 범위 구분 |
| data/cuda-a.csv, data/cupy-a.csv | 환경 A에서 별도로 수행한 CUDA 및 CuPy 구성 비교 |

환경 A는 RTX 4070 SUPER, 환경 B는 RTX 4060 Ti 8GB이다. 공통 조건은 Python 3.14.7, NumPy 2.4.4, CuPy 14.2.0이다. 처리량은 준비 이후 동기화된 KDF 배치 호출을 기준으로 한다. 환경별 성능 측정에서 준비 호출을 포함한 39,200개 출력을 CPU 참조와 대조하였다. 이 저장소에서 재계산하는 자료는 그중 시간 측정 대상으로 기록된 호출이다.

## GPU에서 같은 측정을 다시 수행하는 경우

새 측정에는 저자의 별도 Windows용 실험 키트 `Argon2id_공통조건32_전체패키지_2026-11-05.zip`이 필요하다. 이 저장소만 복제한 상태에서 실행 가능한 범위는 기록된 측정값의 재분석이다. 키트의 SHA-256은 `90b892aa5df5b0c56c63ba2a0ff996ea394e4a684c6c0d9419436f535a3ef74e`이며, 압축을 푼 후 키트 루트의 `README_COMMON32.md`에 있는 준비 및 실행 절차를 따른다. 환경별 드라이버와 VRAM, 빌드 도구, 유휴 조건에 따라 새 측정값은 달라질 수 있다.
